# 1. Purpose

This document defines the business data model of the AI Project & Asset Management Platform.

The Data Dictionary provides a single source of truth for all business entities, attributes, relationships, ownership, validation rules, and lifecycle information.

It is independent of the physical database implementation.

---

# 2. Scope

This document covers:

- Master Data
- Transaction Data
- Workflow Data
- Audit Data
- Configuration Data
- AI Data
- Reporting Data

# 3. Naming Standards

## Entity Names

Use PascalCase.

Examples

- Client
- Project
- Batch
- Asset
- Task

---

## Property Names

Use PascalCase.

Examples

- ClientId
- ProjectCode
- StartDate

---

## Primary Keys

Every entity shall use

```text
<EntityName>Id
```

Example

```text
ProjectId
```

---

## Foreign Keys

Reference parent entity.

Examples

```text
ClientId
ProjectId
TaskId
WorkflowId
```

---

## Audit Fields

Every business entity shall contain

```text
CreatedBy
CreatedDate

ModifiedBy
ModifiedDate

IsDeleted

DeletedBy

DeletedDate

RowVersion
```
