# 1. Purpose

This document defines the business use cases supported by the AI Project & Asset Management Platform.

A use case describes how an actor interacts with the system to achieve a business objective.

Each use case identifies:

- Primary Actor
- Supporting Actors
- Preconditions
- Trigger
- Main Success Scenario
- Alternate Flows
- Exception Flows
- Postconditions
- Related Business Rules
- Related Functional Requirements

# 6. Client Management Use Cases

---

## UC-CL-001 — Create Client

### Goal

Register a new client.

### Primary Actor

Project Manager

### Preconditions

- User is authenticated.
- User has Create Client permission.

### Trigger

User selects **New Client**.

### Main Flow

1. Open Client form.
2. Enter client information.
3. Validate mandatory fields.
4. Save client.
5. Generate Client Code.
6. Record audit log.

### Alternate Flow

Client already exists.

### Exception Flow

Validation failure.

### Postconditions

Client becomes available for project creation.

# 7. Project Management Use Cases

---

## UC-PR-001 — Create Project

### Goal

Create a new production project.

### Primary Actor

Project Manager

### Preconditions

- Client exists.
- User has permission.

### Main Flow

1. Select client.
2. Enter project details.
3. Assign project manager.
4. Configure workflow.
5. Create default milestones.
6. Save project.

### Postconditions

Project enters Planning state.
